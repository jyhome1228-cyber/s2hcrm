# S2H CRM — 2차 UI 디자인 통합 결과

작업일: 2026-11-25
기준 저장소: `jyhome1228-cyber/s2hcrm`
운영 상태: 점검 모드 유지 (`MAINTENANCE_MODE=true`)

## UI 수정 결과
- 12개 CSS 링크를 `styles.css`와 **통합 `crm-ui.css`** 2개로 축소. 기존 순서 그대로 통합해 컴포넌트 동작 보존.
- 실사용되지 않는 `notion-calendar.css`는 로딩 대상에서 제거.
- 더 이상 호출되지 않는 `compactCalendar`, `summaryMonthCalendar` 렌더러와 미사용 월간 더보기 상태 및 이벤트 제거.
- 기본 서체 Pretendard, 포인트 `#0089B3`, 공통 텍스트·간격·라운딩·포커스·호버 스타일 통일.
- 사이드바, 헤더, 콘텐츠 폭 및 모바일 가로형 내비게이션 디자인 통일.
- 공통 버튼(Primary/Secondary/Mini), 입력창, 선택박스, 상태 배지, 검색·필터 컨트롤의 크기·모서리·상호작용 일관화.
- 셀러·상품·일정·활동 테이블의 셀 높이, 헤더, 구분선, 스크롤 테두리 통일.
- 모달 헤더/본문 스크롤/고정 저장 푸터의 레이아웃 통일. 공구 수정·오픈 준비 확인 모달은 별도 특화 스타일을 존중.
- 키보드 Tab 포커스 순환, 최초 입력창 초점, 닫을 때 이전 버튼으로 포커스 복귀.
- 셀러 상세 팝업의 열기/닫기 포커스 복구, Escape 동작 추가.
- 1120px·760px 기준 모바일 반응형 패딩·버튼·테이블 조정 및 `prefers-reduced-motion` 준수.

## CSS 유지보수 방식
1. 기반 호환 규칙: `styles.css`
2. 통합 운영 번들: `crm-ui.css` (현재 웹사이트에서 로딩되는 유일한 추가 CSS)
3. UI 작업 기준: `ui-polish-v2.css` (번들 마지막에 포함된 공통 디자인 규칙)
4. 이전 컴포넌트 원본 CSS 파일들은 저장소에 참고용으로 남아 있음. 독립적으로 새 CSS 링크를 추가하지 말 것.
5. 앞으로 공통 스타일을 수정하면 운영 번들 `crm-ui.css`에도 반드시 재반영하고 쿼리 버전을 갱신할 것.
